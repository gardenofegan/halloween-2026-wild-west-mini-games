# Halloween 2026: Wild West Mini-Games

A collection of 8 Wild West themed mini-games built for a Halloween 2026 party event! 

## The Games

1. **Quick Draw**: Shoot your rival before they shoot you!
2. **Gold Rush**: Mine the most gold by mashing the button!
3. **Lasso Catch**: Time your lasso throws to catch running cows.
4. **Bandit Whack**: Whack-a-mole style game with bandits and barrels.
5. **Dynamite Toss**: Stop the sliding meter in the green zone to blow up the bank vault.
6. **Horse Race**: Jump over hurdles matching your colored guitar strings.
7. **Snake Bite**: Wait for the rattler to strike before you flinch!
8. **Telegraph Decoder**: Memorize and repeat the Morse code signal.

## Tech Stack & Hardware

- **Hardware**:  4 Player Playstation 2 BUZZ USB controller. Each player has 5 buttons: Blue, Orange, Green, Yellow, and Red. 
- **Core Tech**: Vanilla HTML5, CSS3, and JavaScript (ES6+).
- **Graphics**: HTML5 `<canvas>` API with pixel-art image smoothing disabled for crisp rendering.
- **Audio**: HTML5 `<audio>` API with multi-channel support for sound effects.
- **Input**: Gamepad API wrapper handling 4 simultaneous players.
